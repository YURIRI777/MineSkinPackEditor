# MineSkinPackEditor

マインクラフト統合版で使えるスキンパックを作成できるツールです

skin.jsonやmanifest.jsonといったファイルを自動で生成します。
UUIDも自動生成されます。

利用者がスキン画像をアップロードするだけで簡単に.mcpackが作れます。

4dSkinなどは作成できません。普通のスキンのみです
